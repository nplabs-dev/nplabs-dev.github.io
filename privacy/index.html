NP LABS – Privacy Policy

Last updated: 18 October 2026

NP LABS ("we", "us") is an experimental game label developing casual games for mobile and HTML5. This Privacy Policy covers this website, our internal tools and, in general terms, our games. Each game also has its own specific privacy policy, listed below.

This website

This website is a static site hosted on GitHub Pages. We do not use our own cookies, analytics or tracking, and we do not collect personal data through it. GitHub may process technical data (such as IP address and browser information) to serve the site, as described in the GitHub Privacy Statement.

Internal automation tools

NP LABS uses an internal application named "NP LABS Make", connected to the Make.com automation platform. It accesses, in read-only mode, files stored in NP LABS's own Google Drive (promotional images and videos of our games) in order to publish them on NP LABS's official social media channels.

  • The application is used only by NP LABS's own accounts and is not offered to the public.
  • It does not collect data from other users.
  • Data accessed through Google APIs is not sold, shared with third parties, or used for advertising.

NP LABS Make's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
